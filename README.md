# 🌐 TradePilot AI

**Your Intelligent Import & Export Assistant**

TradePilot AI is a smart trade navigation platform designed for **MSMEs, startups, and first-time exporters**. It simplifies global trade by combining AI-powered market intelligence, customs guidance, regulatory compliance, and shipping logistics — all in one intuitive dashboard.

---

## 🚀 Features

- 🧠 **AI Trade Assistant** — Natural language interface to start and guide trade journeys
- 📊 **Market Intelligence** — Real-time insights on target markets and trade opportunities
- 📦 **Trade Journey Tracker** — Step-by-step export/import journey management
- 📄 **Documents Hub** — Manage all trade-related documents in one place
- ⚖️ **Regulations & Compliance** — Country-specific regulatory guidance
- 🚢 **Shipping & Logistics** — Shipping options, costs, and tracking
- 🔐 **Trust Layer** — Verified exporter identity and trust scoring
- 🏛️ **Official Sources** — Direct links to government trade portals
- 📋 **Next Steps** — Actionable recommendations for your trade journey

## 🖥️ Getting Started

Since this is a pure HTML/JS project, no build step is required.

### Option 1 — Open Directly
Simply open `index.html` in your browser.

### Option 2 — Local Server (Recommended)
```bash
# Using Python
python -m http.server 3000
```
Then visit: **http://localhost:3000**
